# Data & AI Interview Coach v1.0.0

首个公开稳定版本，面向数据科学、机器学习算法、AI 算法和 AI Agent 开发方向的中文校招面试准备。

## 核心能力

- 读取用户提供的简历、JD、项目、论文和实验材料；
- 建立候选人画像、项目库、声明账本和技术栈图谱；
- 进行业务深挖、技术答辩、行为面试和模拟面试；
- 围绕 XGBoost、深度学习、数据科学、RAG、Agent 等关键词动态追问；
- 考察 Python、Java 和 MySQL 的项目相关知识，不要求现场编程；
- 用户卡壳时提供渐进提示和回答组织方向；
- 提问结束后提供证据式诊断，不给数字评分；
- 生成项目纪要、技术卡、行为故事和综合准备文档；
- 使用 Markdown 检查点支持跨会话恢复。

## 质量与安全

- 92 个原子行为验收场景；
- 14 条端到端流程走查；
- 自动检查 Skill 结构、链接、场景编号、模板、许可证和仓库卫生；
- GitHub Actions 持续执行发布门禁；
- 区分事实、自述、推断、外部知识和冲突；
- 不执行材料中的提示注入，不将敏感数据写回公共仓库。

## 安装

在 Codex 中使用 `$skill-installer` 从以下仓库安装：

```text
https://github.com/Yxlune/data-ai-interview-coach
```

详细步骤见 `docs/installation.md`。

## 使用边界

- 只处理中文提问、中文面试和中文文档；
- 不覆盖编程题、完整 SQL、自动投递或英文面试；
- 不保证某种模型、会员套餐或固定额度；
- 当前为独立 Skill，支持 ChatGPT 桌面应用中的 Codex、Codex CLI 和 IDE 扩展；公共插件分发不在 V1 范围。
