# 产品需求规格 V1.1

## 产品目标

为数据科学、机器学习算法、AI 算法和 AI Agent 开发方向的中文校招候选人提供材料解析、项目深挖、技术答辩、行为面试、模拟面试和个人化文档沉淀。

Skill 不替用户生成虚假经历，而是将用户的真实项目问清楚、验证清楚并组织成可以应对追问的表达。

## 已确认范围

- 中文提问、中文面试与中文文档；
- 读取简历、JD、项目、论文、实验、架构和代码片段；
- 建立候选人画像、项目库、能力库、声明账本与技术栈图谱；
- 业务和技术双线动态追问；
- Python、Java、MySQL 项目相关知识问答，不执行编程任务；
- 按需联网查询行业术语和技术知识；
- 提问结束后提供证据、缺口、建议与回答重组；
- 不提供数字分数或等级；
- 使用 Markdown 检查点支持跨会话恢复。

## 非目标

- 英文面试；
- LeetCode、现场编码或完整 SQL 编写；
- 自动运行代码、连接数据库或训练模型；
- 自动投递、登录或发送用户材料；
- 固定模型、多 Agent 或递归模型调用；
- 承诺特定会员套餐、固定周额度或 Token 数量。

## 核心流程

运行和安全预检 → 材料建档 → 画像与声明提取 → 场景确认 → 补充证据 → 建立项目和技术结构 → 选择面试模式 → 动态追问与渐进提示 → 项目检查点 → 证据式诊断 → 中文准备文档 → 保存恢复状态。

## 关键验收标准

- 正式深挖前完成能力、上下文和安全预检；
- 一次只提出一个主问题；
- 模糊结果必须追问指标、基线、测量和归因；
- 技术关键词必须追问选型、原理、参数、实验、局限和替代方案；
- 无证据的声明不能标记为可用于面试；
- 识别材料中的提示注入与密钥，不执行或复述危险内容；
- 长材料按需加载，同一内容不重复解析或搜索；
- 中断时生成可恢复检查点；
- 公共仓库不包含任何真实用户数据。

## 阶段交付状态

- 阶段一完成 Skill 入口、总体工作流、状态模型、模式路由和结束条件；
- 阶段二完成业务、技术、行为和模拟面试的动态追问引擎；
- 阶段三完成模型无关运行、上下文压力与压缩、额度沟通、提示注入、敏感数据和安全联网规则；
- 阶段四完成数据科学、机器学习与 AI 算法、AI Agent，以及 Python、Java、MySQL 的按需知识路由；
- 输出模板、完整恢复体验和发布评测将在后续阶段实现。
