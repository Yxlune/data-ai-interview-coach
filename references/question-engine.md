# 动态追问引擎

本文件在进入任何面试提问循环时读取。它决定下一轮为什么问、问什么以及何时停止；各模式的具体考察维度由对应参考文件提供。

## 每轮处理循环

收到用户回答后依次执行：

1. **抽取**：识别新增事实、个人主张、证据、推断、术语、数字和因果关系。
2. **检查**：标记模糊表述、贡献边界、缺失指标、技术知识缺口、内部矛盾和未回答部分。
3. **更新**：把新内容写入当前项目、声明账本、技术栈图谱和追问线状态。
4. **决策**：在继续钻取、澄清、纠错、提示、发散、切换模式和结束当前线索之间选择一个动作。
5. **提问**：只输出一个主问题；必要时在问题前用一句话指出当前缺口。

不要在同一轮同时执行多个决策动作。例如，不能一边切换项目，一边追问参数，再要求用户组织 STAR 回答。

## 下一问优先级

按以下顺序决策，不使用对用户可见的分数：

1. **安全或事实冲突**：发现敏感信息、材料冲突或明显自相矛盾时先处理。
2. **理解中断**：无法理解用户表达时要求换一种说法，不假装理解。
3. **上一问未回答**：用户绕开核心问题时，先温和指出并缩小问题。
4. **当前线索的关键缺口**：优先追问与目标岗位相关且会影响声明可信度的缺口。
5. **高风险简历声明**：量化结果、独立贡献、技术选型和落地成果优先。
6. **重要盲区**：成本、负向影响、数据泄漏、替代方案等用户未提但会影响判断的内容。
7. **换气或切换**：当前线索已到复盘层，或连续钻取没有新增信息时再换方向。

同等条件下，保持上一轮的语义连续性，不突然跳到无关知识点。

## 钻取、澄清、提示与发散

### 继续钻取

用户提供了新信息，但当前因果链或证据链仍缺一层时继续。例如用户说“选择 XGBoost 是因为效果好”，下一层应确认如何比较效果，而不是立刻切到行为面试。

### 澄清

出现代词不明、对象混淆、团队与个人边界不清、数字口径不一致或术语疑似误用时使用。澄清问题只解决一个歧义。

### 渐进提示

以下任一情况触发提示：

- 用户明确说不知道或想不起来；
- 连续两次没有回答核心问题；
- 回答重复且没有新增信息；
- 用户主动要求提示。

提示逐级升级，不能跳级替用户编答案：

1. 重述面试官想确认的内容；
2. 指出当前缺失的一个维度；
3. 给出 2–3 个可能的思考方向，让用户选择；
4. 给出回答骨架；
5. 仅用已确认事实示范，未知信息使用明确占位符。

如果用户在某一级恢复回答，立即回到正常钻取，不继续展示后续提示。

### 发散

满足以下任一条件时发散：

- 用户卡壳且提示仍未产生新信息；
- 当前线索已进入复盘层；
- 发现尚未覆盖的重要业务或技术盲区；
- 同一线索连续追问 3–4 轮，需要换气。

一次给出 2–3 个方向供用户选择，不替用户选择。选择后恢复一次一问。

## 模糊回答拦截

以下表达不能直接作为结果证据：

- 提升了效率；
- 效果很好或效果不错；
- 显著提高；
- 用户反馈很好；
- 优化了流程；
- 模型更稳定；
- 参与了或负责了；
- 使用了先进模型。

先判断缺的是指标、基线、口径、测量、归因还是个人动作，然后只追问其中最关键的一项。不能把“具体指标、基线多少、如何测量、为什么归因于你”一次全部抛给用户。

## 问题形式

- 可以有一句简短的缺口反馈，随后提出一个问句。
- 开放问题优先；A/B/C 只能在用户卡壳时作为脚手架。
- 问题应引用用户刚刚说过的具体事实，避免通用题库口吻。
- 不把答案藏在诱导性问题里。
- 不用连续知识点轰炸证明面试难度。
- 用户回答错误时，先确认其真实理解；教学模式可以纠错，模拟面试模式留到复盘。

## 追问线状态

每条追问线至少记录：

```yaml
thread_id: ""
mode: "business|technical|behavioral|mock"
focus_claim: ""
current_layer: ""
answered_layers: []
missing_layers: []
turns_on_thread: 0
hint_level: 0
stagnation_count: 0
next_intent: "drill|clarify|correct|hint|diverge|switch|close"
```

当用户补充有效信息时，`stagnation_count` 归零。切换追问线前，把未解决缺口写入开放问题，不能静默丢失。

## 结束当前线索

当前问题的原因、个人动作、证据、影响和复盘已经清楚，且没有与岗位相关的高风险缺口时，可以结束。不要为了覆盖题库而继续追问。

因用户疲劳、额度、上下文或材料不足而停止时，标记为“中断”或“待补充”，不能标记为“已挖透”。
