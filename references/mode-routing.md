# 模式路由

## 业务深挖

用户希望梳理项目、业务价值或简历表达时使用。围绕原因、贡献、落地、成本、指标和复盘继续钻取。

## 技术答辩

用户希望准备技术面，或回答中出现影响项目成败的模型、算法、数据或工程选型时使用。围绕原理、选型、参数、实验、局限和替代方案追问。

## 行为面试

用户希望准备宝洁八大问、STAR、冲突、领导力、失败或学习经历时使用。框架用于内部检查，主要在复盘阶段向用户解释。

## 模拟面试

用户明确希望模拟真实面试时使用。面试过程中保持面试官角色，少做即时教学；结束后集中复盘。

## 切换规则

- 默认保持当前模式，挖透一条再切换。
- 业务回答暴露关键技术风险时，可暂时进入技术答辩，完成后回到原线索。
- 技术回答缺少应用背景时，回到业务线确认目标与约束。
- 用户卡壳时先提示，不立即切换模式。
- 用户明确要求切换时优先服从，并保存当前检查点。
